THE CASE OF THE FORBIDDEN PROCESS

05:10. The phone tests are dead.

The first night a brand-new test suite runs on real phones, it comes back red. Both phones. Debug and release.

Verdict: the Sandbox Rule, with a test as accomplice.

  1. Not the Lab. The port error is real, but every one of 5,422 tests still ran and uploaded. A crime scene that keeps working isn't the crime.
  2. Not the Flake. Same 3 tests, same line, two devices, two builds. Flakes don't repeat that precisely.
  3. Not the Code. The desktop ran the same test and it passed. The product works.
  4. The Sandbox Rule. Phone apps may not start other processes. "Operation not permitted" at the exact line that spawns one. The calendar explains why nobody caught it: two green changes, merged hours apart.

Time to verdict: 7 minutes after the agent opened the case.

The easy sentence was "ignore those 3 tests on phones". The agent refused it.
