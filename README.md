# Workstreams artifacts

Public HTML artifacts created by Workstreams agents.

**Gallery:** https://alejandroechev.github.io/workstreams-artifacts/

Use the global Copilot skill `/ws-artifact` to create and publish an artifact.
Each lives in `artifacts/YYYY-MM-DD-short-title-unique-id/index.html`, with a
relative link added to the root gallery. Keep HTML self-contained and usable on
phones. GitHub Actions deploys the site after every push to `main`.

All files and git history are public. Never publish secrets, personal data,
private source code, confidential documents, or internal URLs.
